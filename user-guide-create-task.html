Introduction. This section highlights the key steps when creating a new task. Refer to the Column Explanation page for detailed instructions on each column.

Open Column Explanation
1
Board view

Open the Create New Task view

Instruction

Use this view to create and set up new tasks easily.

Note: It sits with the other views along the top of the board (Arrangement By Workflow).

2
Board access

Make sure everyone can open the board

Instruction

Ensure the Tasker, Taskee and relevant PIC have access to the board.

Note: Only authorised users should be invited. Board access must be granted before users can view or update their assigned tasks.

3
Task columns

Fill in the task columns

Instruction

Add the task with + Add assignment / task, then fill in each column. Select a column below to open its full instruction in the Column Explanation.

Note: Refer to the Column Explanation page for detailed instructions on every column.

Select High, Medium or Basic, based on complexity and workload.

Column Explanation, step 10 →
4
Updates panel

Add an update with an @mention

Instruction

Open the task’s update bubble to post instructions or follow-up details. Use @mention so the right person is notified.

Sample

An update that mentions the Taskee: “@Taskee Please apply for a cash advance for this road tax renewal.”

Note: The full update steps are in Column Explanation, step 4.

5
Columns: PIC and Taskee

Select the PIC before a shared email

Instruction

When using a shared email account, FIRST select a dedicated PIC to identify the person responsible for handling the task and its notifications, BEFORE entering the shared email address in the Taskee column.

Note: This ensures clear task responsibility and proper follow-up.

6
Subitems

Break the work into subitems

Instruction

Open the task’s arrow to add subitems for each stage of the work, such as Quotation, Invoice, Payment and Collection.

Note: Use subitems to track individual work stages. Update their status as each stage progresses.

7
Column: Work Status

Assign the task

Instruction

Only change the Work Status to Assigned once the task is fully set up and the responsible people are selected.

Important: Complete all required task details and assign the responsible person before changing the Work Status to Assigned.
